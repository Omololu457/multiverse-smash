1) HOW TO OPEN THE GAME (fullscreen, in its own window)
------------------------------------------------------------

Open the Terminal app, then paste these two lines:

    cd /Users/omololu/Desktop/project/multiverse-smash
    npm run desktop

That's it. The game opens in its OWN window, already in FULLSCREEN
(not a browser tab). Give it a few seconds the first time.

  • To QUIT the game:            press  Cmd + Q
  • To leave fullscreen:         press  Ctrl + Cmd + F
  • Nothing happened / error about "electron"? Run this ONCE, then
    try "npm run desktop" again:
        cd /Users/omololu/Desktop/project/multiverse-smash/electron
        npm install
        cd ..
        npm run desktop

4) CONTROLS CHEAT SHEET  (Player 1, keyboard)
------------------------------------------------------------

    Move .................... A / D
    Jump / Up ............... W
    Crouch .................. S
    Block (guard) ........... ;   (semicolon)
    Light attack ............ J
    Heavy attack ............ K
    Up-Attack (launcher) .... I     <- pops both players up for air combos
    Special ................. L
    Ultimate (full meter) ... U
    Grab .................... O
    Charge / Transform ...... P
    Dash .................... double-tap A or D

    SPECIALS: press L by itself, or hold a direction + L:
       L            = 1st special
       S + L (down) = 2nd special
       forward + L  = 3rd special / movement special
       U (full bar) = Ultimate / Domain / finisher

6) PLAY WITH A FRIEND  (desktop app — updated 2026-11-22)
------------------------------------------------------------

  1. Open the desktop app (section 1) and press PLAY WITH A FRIEND
     on the title screen.
  2. Wait a few seconds until the tag next to the link says
     WORKS ANYWHERE. That link works for a friend on any network
     (it goes through a free Cloudflare link). Before that, the
     link says SAME WI-FI ONLY.
  3. Send the link (Copy link), OR let your friend scan the QR
     code with their phone camera.
  4. Anyone who opens that SAME link presses JOIN THE GAME and
     plays in their browser — no download. You each pick your own
     fighter; you pick the stage.

  • Keep the game open the whole time — closing it (or pressing
    Back) closes the room, and the next time you get a NEW link.
  • Up to 4 players: you + 3 friends, all on the SAME link. With one
    friend it's 1 vs 1 (you pick the stage); with 2 or 3 friends it
    starts a FREE-FOR-ALL as soon as everyone has picked.
  • Friends can join while you're picking — the screen says how many
    are in the room. If someone leaves mid-match, the match ends and
    everyone still there picks again.
  • If it only ever says SAME WI-FI ONLY, the internet link
    couldn't be made (the small text under it says why) — your
    friend then has to be on your Wi-Fi.
