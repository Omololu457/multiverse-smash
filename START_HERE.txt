1) HOW TO OPEN THE GAME (fullscreen, in its own window)
------------------------------------------------------------

Open the Terminal app, then paste these two lines:

    cd /Users/omololu/Desktop/project/multiverse-smash
    npm run desktop

That's it. The game opens in its OWN window, already in FULLSCREEN
(not a browser tab). Give it a few seconds the first time.

  • To QUIT the game:            press  Cmd + Q
  • To leave fullscreen:         press  Ctrl + Cmd + F
  • Nothing happened / error about "electron"? Run this ONCE, then
    try "npm run desktop" again:
        cd /Users/omololu/Desktop/project/multiverse-smash/electron
        npm install
        cd ..
        npm run desktop


------------------------------------------------------------
2) OPEN IT IN A BROWSER INSTEAD (backup way)
------------------------------------------------------------

    cd /Users/omololu/Desktop/project/multiverse-smash

4) CONTROLS CHEAT SHEET  (Player 1, keyboard)
------------------------------------------------------------

    Move .................... A / D
    Jump / Up ............... W
    Crouch .................. S
    Block (guard) ........... ;   (semicolon)
    Light attack ............ J
    Heavy attack ............ K
    Up-Attack (launcher) .... I     <- pops both players up for air combos
    Special ................. L
    Ultimate (full meter) ... U
    Grab .................... O
    Charge / Transform ...... P
    Dash .................... double-tap A or D

    SPECIALS: press L by itself, or hold a direction + L:
       L            = 1st special
       S + L (down) = 2nd special
       forward + L  = 3rd special / movement special
       U (full bar) = Ultimate / Domain / finisher
