HOW THE INPUTS WORK
-------------------
FULL-KIT characters use SUMMON-THEN-SELECT:
  1. Stage a clone formation:   down, down, up  +  Special   ( ↓↓↑ + Special )
  2. Within the ~1 second window, press Special AGAIN with a held direction
     (or press Ultimate) to pick one of the 6 moves.

LIGHT-KIT characters (Sasuke, Obito) use a DIRECT TRIGGER:
  ↓↓↑ + Special with a held direction fires the move immediately (no formation).

BUTTON MAP  (Player 1 keyboard;  gamepad in [brackets])
  Down  = S            Up = W
  Special = L          [ Triangle / Y ]
  Ultimate = U         [ L2 / R2 ]
  Forward / Back       = toward / away from the opponent  (facing-relative)

SELECT DIRECTIONS (full kit) — pressed AFTER the summon, within the window
  Pure Attack  = (neutral) + Special
  Grab         = Forward   + Special
  Ranged       = Back      + Special
  Defensive    = Up        + Special
  Deception    = Down      + Special
  Swarm        = Ultimate  (while the formation is staged)

Notation below:  "↓↓↑+L -> L"  means  summon (↓↓↑+Special)  ->  select (press L).
Keyboard is first, gamepad second.

========================================================================
NOTE — IN-GAME MOVE LIST SCREEN
========================================================================
These per-character move NAMES do NOT appear on the in-game Move List screen
(its kit panel is driven by getKit() in kits.js, a separate system from
cloneChoreography.js). The Move List's "Controls" tab (and the pause Controls
overlay) DO show the generic input:
  "Clone Summon — ↓↓↑ + Special"  +  "...then hold a direction + Special to pick:
   Neutral=Pure Attack · Down=Deception · Up=Defensive · Back=Ranged · Fwd=Grab · Ultimate=Swarm"
...but not the individual named moves above.

NARUTO uses his own dedicated engine (narutoChoreography.js), but as of the
2026-10-08 pass he is on the SAME roster-standard summon-then-select scheme:

  Summon          ↓↓↑ + Special          (roster-standard; alternates kept: Up+Special, ↓↑+Special)
  Pure Attack     Uzumaki Barrage        ↓↓↑+L -> L      (also direct: Down+Special, or ↓→↓→)
  Ranged          Shadow Clone Shuriken  ↓↓↑+L -> Back+L
  Defensive       Substitution Escape    ↓↓↑+L -> Up+L
  Grab            Clone Flank Strike     ↓↓↑+L -> Fwd+L
  Swarm           Two Thousand Combo     ↓↓↑+L -> Ultimate   (while the formation is staged)
  (Naruto has no Deception sequence — a Down-select falls back to Uzumaki Barrage.)

  ULTIMATE = NINE-TAILS (Kurama Avatar / Tailed Beast Bomb):
    Neutral Ultimate  = Nine-Tails        (alternates: Down+Ultimate, or ↓←↓←+Ultimate)
  Other specials unchanged: Dark Rasengan = Back+Special (or ↓←↓←); Chakra-Arm Strike = Fwd+Special (or ←↓→).
