# MSV1 — Ninja framework (`ninja.js`)

`ninja.js` is a profile-driven module layered on `rangers.js`, the same way `flight.js`, `drones.js` and
`rangers.js` are shared modules. A Ninja Storm Ranger is **one `registerNinjaProfile(rosterKey, {...})` call**
plus a roster entry. The framework owns every shared system. A profile supplies only numbers, a move table and
which optional modules it uses.

| File | Role | Sim / render |
|---|---|---|
| `ninja.js` | framework: Ninja Power, Streak, Smoke Vanish, Shadow Clones, Ninja Mirror, Barrier, optional burrow / traps / REV / float, engine hooks | **sim** |
| `ninjaCommand.js` | generic command layer (`updateNinjaCommand`): double-tap, Charge commands, normals / gatlings / specials from `profile.commands` | **sim** |
| `nsData.js` | Shane + Dustin profiles, move tables, command tables, roster entries, strip → move map | data |
| `nsSupers.js` | the four scripted supers / ultimates (sim-clock scripts) | **sim** |
| `nsFx.js` | illusion / clone / smoke / streak-tail / trap / bubble / HUD drawing, cue → sound | **render only** (reads `f._ninja`) |
| `nsSound.js` | WebAudio synth cues `nsr_*` (Shane) / `nsy_*` (Dustin); reuses S.P.D. Red's impact / blocked / zap | render only |
| `nsKit.js` | Move List (kits.js) | metadata |
| `nsHarness.js` | `__harness.ninjaTest` (tests only) | test |
| `msv1Sprites.js` | generated by `tools/msv1/pack_msv1.py` (cell 260×136, strip frame counts) | data |

## Built on S.P.D. Red (rangers.js), not copied from him

* `registerNinjaProfile` also registers a **rangers.js profile** for the same key, with `blink = { ...S.P.D. Red's
  tapWindow 12 + run {speed 8.4, walk 5.6}, vertical: true }`.
* Every tick, `tickNinja` calls `rangers.tickRanger` with `r.blinkVeto = true`. The rangers.js detector does the
  double-tap detection with S.P.D. Red's exact window and diagonal rule, then hands over `r.pending` instead of
  blinking. The ninja **streaks** in its place.
* Run: `physics.js` already applies `rangerWalkMul` to any fighter with `_ranger`. Holding the streak direction
  through the recovery sets `r.running`, which gives S.P.D. Red's 10.5 px/f run.
* Speed tier: `stats.speed 88` (walk 7.0 px/f). The engine's generic stat pass leaves bespoke fighters at
  84 / dash 16, so `tickNinja` and `ninjaRoundReset` restore `profile.stats`. This is the same pattern Robin,
  Batman and Elastigirl use.
* Tests: `harness/msv1_scen_a_core.mjs` measures walk and run for S.P.D. Red and both ninjas in the **same
  scenario** and asserts they are equal (7.0 / 10.5 px/f).

**"Teleport" in the brief.** The game has no teleport button: S.P.D. Red's teleport *is* the double-tap. So:

| Brief | Input here |
|---|---|
| Streak (double-tap Teleport) | double-tap ←← / →→ (Shane in the air: also ↑↑ / ↓↓, and ↗ / ↘ held in the first 2 frames) |
| Teleport + Light + Heavy (Vanish) | **Charge** + Light + Heavy within 4 ticks |
| ↓↓ + Teleport (Mirror) | ↓↓ + **Charge** |
| Teleport during the Mirror (Swap) | **Charge** alone |
| → + Teleport (Barrier) | → + **Charge** |
| ← + Teleport (Shadow Clones) | ← + **Charge** |

Charge (`p` / pad) never charges meter for a ninja. The `abilities.js doEnergyCharge` hook and the `game.js` charge
exclusion `!isNinja(fighter)` handle this.

## Systems

### A. Ninja Power — `np: { start 50, max 100, regen 6/s (not while streaking), onHit 4 }`
`f._ninja.np` is a slim bar under the health bar with notches at 25 / 50 / 75. It is separate from the engine's
super meter (`f.energy`, which pays for supers and ultimates in bars of 50).

### B. Ninja Streak — `streak: { distPct .40, travel 8, intangible [2,6], cost 10, chain 3, thirdCost 20, recovery 14, cancelFrom 9 }`
* Travels 40% of the screen (`RANGER_SCREEN`, 1280 → 512 px) in 8 frames, drawn as the R3 strip with a tail and
  speed lines.
* Projectile-intangible on frames 2–6 only (asserted per frame). It is **not** strike-invulnerable.
* Passes **through** the foe. It never ends inside them: it clears to the far side, or stops in front against a wall.
* Chains ×3 inside the recovery: 10 + 10 + 20 NP. After the third streak, `chainLock` makes the full recovery play out.
* **Streak Strike**: Light or Heavy pressed during the travel hits once on the way through for 45 (blunt).
* Recovery is 14 frames, and specials cancel it on frames 9–14.
* Not enough NP on the ground: the double-tap just runs.
* Optional `streak.air: { perAirtime, eightWay }` (Shane) and `streak.underground` (Dustin's Tremor Streak while
  burrowed).

### C. Smoke Vanish — `vanish: { cost 30, pop 6, gone 6, fade 8, behind 70, above 150 }`
* Smoke pop, then 6 frames gone (the body is clipped), then reappears behind the foe, or above them when ↑ is held.
* In blockstun it is an escape instead: 40 NP, 6 invulnerable frames, 12 s cooldown.

### D. Shadow Clones — `clones: { max 2, dmgPct .6, cost 35, strike 60 }`
* Choreography: hand sign (t8), smoke pop (t14), staggered fan-out (t16 / t22, 6-frame glide), unison strike (t40),
  smoke exit (t52).
* Each clone gets a ±6° tilt, chosen in the sim by hash and drawn by the renderer.
* Clone hits deal 60%, are `noKO`, and grant NP.
* The super scripts reuse the same engine (`startCloneJob(f, opp, { steps, slots, pose, dmg, fixedScale })`).
  `clonechoreo.js` does not exist in this repo, so the clone engine lives in ninja.js behind that one function.

**Clone vs clone (decision).** A ninja clone pops on **anything that would hit a fighter**: the foe's live attack
box, or any projectile the foe owns. That includes Naruto-family clone strikes and summons, because those reach
the clone as the foe's attack box or projectiles. Ninja clones only ever target the foe's **body**. They never
target the other side's clones, illusions or summons. So:
* ninja vs ninja: the clones trade only through the bodies, with no clone-on-clone hit table;
* ninja vs Naruto: shadow clones can pop ninja clones, but ninja clones ignore Naruto's.

This keeps every clone interaction a pure function of the fighter state that is already in `GAME_STATE`.

### E. Ninja Mirror — `mirror: { cost 50, frames 480, gapPct .30, swapCost 10, swapFrames 6, maxSwaps 3, glintEvery 90, mode, echoDelay 8, dmgPct .5, meterPct .5, counter }`
* **One real body** (the fighter object itself, the only hurtbox) plus one **illusion** (`m.ix / m.ifeet`, just
  coordinates). They stand 30% of the screen apart.
* Which spot becomes real is `rangerHash(seed, frame, player, slot 31) < .5`. Identity is `GAME_STATE` only.
* **Identity rules (no leaks).**
  * The renderer draws both with the same sheet, pose ring and colours.
  * The only tell, visible to both players: the illusion casts **no ground shadow** (the real body's shadow is drawn
    explicitly while the Mirror is up) and its visor **glints every 90 frames**.
  * HUD, bubbles and sounds never reveal the real one.
  * The CPU guesses by the tell, with a difficulty-rated success chance, otherwise by hash (Phase 8).
* **Swap** (Charge): both pop and trade places over 6 frames. 10 NP each, at most 3 per Mirror.
* `mode: 'echo'` (Shane, Wind Mirage): the illusion replays Shane's body motion and **live hitbox 8 frames late**.
  Those hits deal 50%, are `noKO`, deal no chip and give 50% meter. Projectiles are echoed as ninja-owned shots.
* `mode: 'decoy'` (Dustin, Earth Double): a still, guarding decoy. Dustin can burrow to it and swap from underground.
* **Hit the illusion** (foe attack box or projectile): no damage to anyone; it pops, `counter` fires, and the
  Mirror ends. The counter is `{ kind: 'tornado', hits, dmg, every, launch }` (Shane, 3 × 18 then a launch) or
  `{ kind: 'eruption', dmg, wall }` (Dustin, 80 with a wall-bounce).
* **Hit the real one**: the Mirror ends. It also ends when time runs out (480 frames).
* Ultimates set `m.frozen` to own the illusion's pose and spot.

### F. Ninja Barrier — `barrier: { cost 25, parry 8, dome 30, kind, reflectMul 1.2, absorb 2, armorFrames 60, counter }`
* The first 8 frames are a **parry**: a melee hit is spent and the attacker staggers (18 frames of hitstun). This
  goes through the `combat.js` evade hook.
* After the parry window:
  * `kind: 'reflect'` (Shane, Wind Ward): a projectile met during the parry is **reflected**. Ownership flips and
    speed and damage are ×1.2. Projectiles that reach the R19 dome are erased.
  * `kind: 'armor'` (Dustin, Rock Hold): absorbs 2 hits for 1 s, then a shockwave `counter` of 70 within 130 px.

### Optional modules (profile-gated)
| Field | Who | What |
|---|---|---|
| `burrow { cost, frames, sink, speed }` | Dustin | hold Special after ↓↓. Underground at run speed. **Only lows / ground hits** reach him (`ninjaEvades`). Release = Erupt. |
| `traps { max, life, dmg, radius }` | Dustin | Earth Kunai floor traps (max 2, 6 s), 45 + trip |
| `rev { every, max }` | Dustin | a pip per 48 frames of running (max 3). The next streak or special spends all pips at +10% each. Lost on block or hit. |
| `float { frames, fall }` | Shane | Wind Float: hold Jump while falling, 72 frames per airtime, capped fall, never climbs |
| `airMul` | both | air speed ×1.10 (Shane) / ×0.90 (Dustin). The base speed is remembered, so slows are never stomped. |
| `weight` | both | knockback divisor (`ninjaKnockback`) |
| `quotes { intro, win, vs: { key: { line, reply } } }` | both | text bubbles (render reads `f._nsBubble`) |

## Adding a third ninja (no new code)
```js
registerNinjaProfile('ns_blue', { color: '#2a6cff', blink: { tapWindow: 12, run: { speed: 8.4, walk: 5.6 } },
  mirror: { mode: 'decoy', counter: { kind: 'eruption', dmg: 50 } }, moves, commands, supers: {} })
// + a characters.js roster entry with the same key → isNinja() is true, every hook below already applies.
```
`harness/msv1_scen_*` registers a dummy third profile at runtime, retags a fighter with it, and runs streak,
mirror, barrier and clones through the unchanged engine (Phase 8).

## Determinism
All gameplay state lives on `f._ninja` and `f._ranger` as plain JSON, and `ninjaSnapshot(f)` is pushed into the
replay / LAN checkpoint. Randomness comes only from `rangerHash(match seed, frame, player index, slot)`; there is
no `Math.random`. Smoke drift, tilts, speed lines, sparks, glints and camera punch are render-only (`nsFx.js`).
