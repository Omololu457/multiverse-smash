WHAT I FOUND AT A GLANCE
------------------------
The game is FAR bigger than a hobby project. Real numbers from the pass:
  - 99 playable characters across 20+ franchises
  - 891 skin variants, 20 stages, 138-track music system w/ playlists
  - A genuinely deep combat engine: launchers, juggles, wall-splat,
    parry, clash, flawless block, combo breaker, comeback finisher,
    grabs/throws, super armor, tech rolls, per-char counters, domains,
    transformations, summons/shadow clones, projectiles w/ reflect+pierce
  - 9 working modes (Arcade, Tower, VS, PvP local, Training, Bracket,
    FFA, AI-Spectator, Tutorial) + a personality/Big-Five system

So this is NOT "add basic features" territory. The engine is mature.
The gaps that actually matter for POPULARITY are:
  1. NO online play (single biggest ceiling on player count)
  2. Onboarding/retention loop is thin (no forced tutorial, no daily hook)
  3. Story mode is a "Coming Soon" stub
  4. A pile of placeholder art / attribution blockers that read as "unfinished"
  5. Combat has depth but few UNIVERSAL expressive mechanics that ALL
     characters share (which is where "shadow clones for everyone" comes in)

The rest of this file expands all of that.


========================================================================
 SECTION 1 — THE BIG SWINGS (headline gameplay features)
========================================================================
These are the "put it in the trailer" ideas. Each is a system, not a tweak.

[P1] 1.1 UNIVERSAL "ECHO / SHADOW-CLONE" MECHANIC  (L)
    You already have a real shadow-clone system (summons.js) but it's
    locked to Naruto / Minato / Hashirama. The big swing: generalize the
    IDEA into a universal comeback/expression mechanic every character can
    use, reskinned per franchise so it never feels copy-pasted.
      - Spend meter to spawn a 1-hit "echo" of yourself that mimics your
        last attack, then poofs on contact (the engine already does
        mimic + hit-reveal + poof — see summons.js updateShadowClone).
      - Reskin per universe: Naruto=shadow clone, Goku=afterimage strike,
        Flash=speed-mirage, Gojo=Blue clone, Ben10=alien echo, etc.
      - Two flavors worth prototyping:
          (a) SETPLAY echo — place it, then send it on one rush (already
              exists as "CLONE RUSH" for Naruto, summons.js:184 — promote it)
          (b) ASSIST echo — press a button mid-combo, echo repeats your
              current move for an extension/mixup
      - This gives the roster a shared, teachable, hype mechanic AND
        reuses code you already wrote. Highest bang-for-buck "big" idea.

[P1] 1.2 REAL ONLINE PLAY  (L, but THE popularity unlock)
    Right now Online is a dev-locked "netcode not implemented" stub
    (game.js ~11696, account.js:606 has the TODO hooks already stubbed).
    Nothing grows a fighting game like online. Options in effort order:
      - EASIEST: async / "ghost" play — upload replays (you already have a
        deterministic input-replay system in replay.js), let players fight
        each other's recorded ghosts. Ships without real netcode.
      - MEDIUM: lobby + delay-based netplay over WebRTC (browser-native,
        no server). Good enough for friends/Discord matches.
      - HARD (the dream): rollback netcode. Your sim looks deterministic
        (seeded RNG in rng.js, replay desync detection) which is the
        precondition for rollback. Big project but you're closer than most.
    Even shipping (a) or (b) would 10x reach.

[P1] 1.3 STORY / ARCADE-PLUS "MULTIVERSE FRACTURE" CAMPAIGN  (L)
    STORY_MODE is a placeholder (game.js:793, ui.js:1439). You already
    have: per-character arcade endings, rival dialogue, 15-chapter design
    notes, cinematics galore. Wire them into an actual node-map campaign:
      - Branching chapter select, light dialogue between fights (arcade
        rival system already does 2-line exchanges — reuse it)
      - Boss gauntlets using existing boss/armor system (combat.js _bossArmor)
      - Unlock characters/skins as story rewards (hooks exist in unlocks.js)
    This is mostly ASSEMBLY of things that already exist. High perceived value.

[P2] 1.4 TAG / 2v2 TEAM BATTLES  (L)
    FFA already supports 3-4 fighters + teams. A proper 2v2 tag mode
    (call-in assists, tag-cancel combos) would be a marquee mode and
    leans on the summon/assist code. Marvel-vs-Capcom energy.

[P2] 1.5 STAGE-INTERACTION / DESTRUCTIBLE ARENAS  (M)
    Only 2 of 20 stages have hazards (stageHazards.js). Add:
      - Wall-bounce/stage-transition on big hits (you have wall-splat already)
      - Interactive hazards per stage (Shibuya rail exists — template it out)
      - Breakable backgrounds / stage-specific KO cinematics
    Cheap visual spectacle that makes each of the 20 stages feel distinct.

 SECTION 2 — COMBAT DEPTH (mechanics that reward mastery / "feel better")
========================================================================
The engine is deep but a few universal systems are half-built or missing.
These make the game "flow better" — your words — for everyone.

[P1] 2.1 FINISH THE UP-BLOCK / HIGH-LOW SYSTEM  (M)
    combat.js:236-250 has a getHitLevel/isOverheadAttack CLASSIFIER built
    and propagating, but the DEFENSE reward is explicitly deferred and
    low-block was removed (combat.js:240). Right now blocking has no
    directional depth. Finishing this adds real mixup/mind-game:
      - Overheads must be stood-blocked, lows must be crouch-blocked
      - You already tagged 3 heavies as overhead (jason/alt_sukuna/bardock)
    This is the single most "fighting-game-complete" missing mechanic.

[P1] 2.2 EXPLICIT FRAME ADVANTAGE + BLOCKSTUN TUNING  (M)
    Frame advantage is currently IMPLICIT (hitstun vs blockstun math only).
    Your own memory notes flag "no frame-advantage math." To make combos
    and pressure feel intentional rather than accidental:
      - Define on-hit / on-block advantage per move and tune to it
      - Show it in Training mode (you already draw a frame overlay, ui.js:3628)
    Makes neutral and pressure legible = the game "flows."

[P2] 2.3 PUSHBLOCK / GUARD-CANCEL  (S-M)
    Defender has no way to create space — only the attacker's pushX exists.
    A meter-cost pushblock (advancing guard) gives defense agency and
    breaks unfair corner pressure. Small, high-value.

[P2] 2.4 UNIVERSAL REVERSAL / WAKEUP OPTION  (M)
    Counters exist but are bespoke per character (Rengoku/Baki/Kurapika).
    A universal meter-burn reversal (or "burst") gives everyone a defensive
    out and standardizes the escape game. Combo-breaker code (combat.js:497)
    is a good starting template.

[P2] 2.5 THROW TECH / THROW MIXUP CLARITY  (S)
    Grabs/throws exist (combat.js:2416) with a pre-grab tech window, but no
    tech AFTER a grab connects, and Ben-10 aliens have NO grab at all (gap
    flagged in ROSTER_MOVESET_DATA.md:384). Standardize: every character
    gets a grab; add a tech-throw window. Fixes a real asymmetry.

[P2] 2.6 MOVEMENT TECH POLISH  (S-M)
    You have dash, air-dash, double/triple jump, jump-cancel launchers.
    Consider: a universal short-hop, a run-brake/wavedash-ish option, and
    consistent air-dash rules (currently very_high mobility chars get 2).
    Movement is where "flow" lives — small tuning pays off hugely.

[P2] 2.7 METER-USE VARIETY  (S)
    Energy currently gates specials/ultimates/domains. Add optional spends:
      - EX-specials (spend 25 for a stronger version — reuses existing FX)
      - Meter-burn combo extenders
    Gives players more to DO with the bar than "wait for ultimate."

[P2] 3.5 RANKED / MMR  (M, needs online first)

[P2] 3.6 SHAREABLE MOMENTS  (S-M)

[P2] 3.7 SPECTATOR / TOURNAMENT POLISH  (S)
